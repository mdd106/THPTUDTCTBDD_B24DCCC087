# Ứng dụng Quản lý Công việc (Task Manager Mobile App)

Ứng dụng quản lý công việc chuẩn giao diện Mobile được xây dựng với HTML5, Tailwind CSS và JavaScript.

## 📱 Các Màn Hình Ứng Dụng

1. **Màn hình Đăng nhập (Login)**
   - Ô nhập Username & Password
   - Nút **Đăng nhập** chuyển hướng vào Dashboard
   - Text link chuyển hướng đến trang Đăng ký

2. **Màn hình Danh sách công việc (Task Dashboard)**
   - **Header**: Ảnh đại diện tròn, Tên 'Nguyễn Văn A', ID/Chức danh 'abc123'
   - **Nhóm 1 - Công việc hôm nay**: Tiêu đề có nút `+` để mở màn hình Thêm mới, danh sách công việc kèm checkbox đánh dấu hoàn thành
   - **Nhóm 2 - Công việc sắp tới**: Danh sách thẻ card hiển thị thời gian & ghi chú

3. **Màn hình Thêm công việc mới (Create Task)**
   - Tiêu đề 'Thêm mới' cùng nút 'Quay lại'
   - Form nhập: Tên công việc, Thời gian hoàn thành (Date/Time picker), Ghi chú (Textarea)
   - Nút **Lưu / Tạo công việc**

## 🚀 Hướng Dẫn Chạy Dự Án

- Mở trực tiếp file `index.html` bằng trình duyệt web bất kỳ (Chrome, Safari, Edge, Firefox...).
- Hoặc chạy qua Live Server trong VS Code / Android Studio.
